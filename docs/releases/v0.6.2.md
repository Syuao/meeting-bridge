# Meeting Bridge 0.6.2 · 划词复制修复

修复划词后偶发未复制的问题，并让 Qwen-MT 的账户错误显示具体原因。

- 从正文旁的空白处开始拖选，也会在松手后复制并追加草稿。
- 复制在侧栏仍获得焦点时优先完成，再填入网页草稿；双击扩选、松手后选区更新及连续选句不再漏触发。
- 复制失败时正文上方出现「重试复制」，点击只重新复制，不重复填入。
- Qwen-MT 返回 `Arrearage` 时明确提示账户欠费或状态异常，暂停请求，处理账户问题后可手动重试。HTTP 400 不再一律误报为参数错误。

## 下载与更新

- Apple Silicon Mac、macOS 13+：下载 **`MeetingBridge-0.6.2-macOS-arm64.zip`**。先停止监听，解压后运行 `Install.command`，再在 `chrome://extensions` 重新加载 Meeting Bridge。
- **`MeetingBridge-0.6.2-extension.zip`** 只含扩展。此次也更新了本机桥接程序；要获得 Qwen 错误提示修复，请使用完整 Mac 包更新。
- **`SHA256SUMS.txt`** 提供两个 ZIP 的校验值。GitHub 自动生成的 Source code 是源码快照。

更新保留本机 API 配置。无需刷新正在编辑的聊天网页；扩展会重新连接已绑定对话。完整安装步骤见[安装说明](https://github.com/Syuao/meeting-bridge/blob/main/distribution/README.md)。

## 验证与限制

71 项 Node 测试及 18 项本地浏览器交互检查通过，覆盖复制失败重试、连续划选、草稿追加、翻译恢复和安装时保留配置。交互检查使用模拟剪贴板和对话页面，不代表所有 Chrome 环境均已实测。

云服务的欠费或账户异常仍需在服务商账户中处理，插件无法代为恢复额度。包内不含 API 密钥、云额度或本地 Whisper 模型；API 用量另计。本次仍免费、MIT 开源，未上架应用商店，采集程序采用临时签名，尚未进行 Apple 公证。
