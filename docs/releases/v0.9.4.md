# Meeting Bridge 0.9.4

- 新增火山引擎豆包 Streaming ASR 2.0 Provider，保留阿里云 Qwen / Paraformer。
- 设置中可选择转写服务，豆包默认使用 `volc.seedasr.sauc.duration`，支持配置 concurrent Resource ID。
- API Key 只由本机 Host 管理；支持 `DOUBAO_API_KEY`、`DOUBAO_RESOURCE_ID` 环境变量。
- 支持 16kHz/16-bit/mono PCM、200ms 实时分包、中间结果和最终二遍结果、会话内 speaker ID。
- 新增协议和结果处理测试；未配置真实豆包密钥，云端实测待配置后进行。
