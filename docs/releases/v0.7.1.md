# Meeting Bridge 0.7.1 · 连续划选性能与输入框恢复

降低长时间转写后连续划选的页面负担，改进聊天网页输入框重新渲染后的定位和恢复。

- 音量更新只更新音量条，不再附带整份历史或刷新转写正文。
- 跟随最新时只渲染最近 200 段，复用时间格式化器；全部历史仍保存，可加载更早文字或导出。
- 识别带聊天标签的输入框，跳过隐藏旧输入框和代码编辑器；输入框短暂消失时自动重试。
- 已打开网页的旧接收脚本会自动更新；新增「对话与采集设置 → 重连输入框」，检查连接时不改动草稿。
- 取消空闲时反复扫描聊天正文，并避免相同的排队失败反复广播和保存历史。划词仍自动复制、按顺序追加草稿，由使用者发送。

## 更新

停止监听后安装 `MeetingBridge-0.7.1-macOS-arm64.zip`，在 `chrome://extensions` 重新加载 Meeting Bridge 并打开侧栏。已有 0.7.0 本机桥接的用户也可更新扩展目录。源码用户更新后运行 `python3 install.py`。不需要刷新正在编辑的聊天网页。

重载前尚未填入的旧选句会保留在「已选」历史中，需手动选择填入，避免把过时的排队问题突然追加到现有草稿。

## 验证范围

78 项 Node 测试、21 项本地侧栏交互检查、9 项浏览器输入框恢复检查通过。2,400 段模拟记录的本地对照测试显示划选处理明显缩短；这不等于真实 ChatGPT 页面或系统剪贴板的端到端延迟保证。详见仓库验证说明。

Apple Silicon、macOS 13+。公开下载免费，云 API 另行计费。安装包不含密钥或历史，采集程序仍使用临时签名，未获 Apple 公证。
