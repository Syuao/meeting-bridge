# Meeting Bridge 0.7.0 · 可选 Paraformer 实时转写

新增「云端转写模型」选择，可在 Qwen 实时版和 Paraformer 实时版之间切换，继续使用原来的实时正文、翻译、历史和划词填入。

## 使用方法

1. 停止监听，展开「对话与采集设置」。
2. 输入来源选择阿里云，再在「云端转写模型」选择 **Paraformer 实时版**。
3. 使用北京地域的百炼密钥，点击「测试转写连接」，成功后开始监听。原有北京密钥可以直接复用。

选择后自动保存；旧配置默认保留 Qwen。监听或测试期间禁止切换，避免当前语音流被中断。模型选择只影响转写，不更改中文翻译服务、已有历史或对话绑定。

Paraformer 使用 `paraformer-realtime-v2`，按其时间戳适配实时语段更新。它仅支持北京地域；本版尚未接入 Paraformer 云端热词表，「专业术语」输入仅用于 Qwen，切换时会禁用并保留已有内容。

## 下载与更新

- **`MeetingBridge-0.7.0-macOS-arm64.zip`**：完整 Mac 更新包，适用于 Apple Silicon、macOS 13+。停止监听，运行包内 `Install.command`，再到 `chrome://extensions` 重新加载扩展。
- **`MeetingBridge-0.7.0-extension.zip`**：仅扩展，本次需要同步更新本机桥接程序，已有用户也应优先使用完整包。
- **`SHA256SUMS.txt`**：下载文件校验值。

源码安装用户更新源码后运行 `python3 install.py`，再重新加载扩展。无需刷新正在编辑的聊天网页。详见[安装说明](https://github.com/Syuao/meeting-bridge/blob/main/distribution/README.md)。
