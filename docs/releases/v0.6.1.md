# Meeting Bridge 0.6.1 · 首个公开体验版

Mac 系统声音实时转写、中文翻译，以及 ChatGPT / DeepSeek / 千问 / Qwen 网页草稿助手。源码和本次 Release 免费公开，MIT 许可。未上架 Chrome 应用商店。

## 下载哪个文件

- **`MeetingBridge-0.6.1-macOS-arm64.zip`**：首次使用下载这个。Apple Silicon Mac、macOS 13+；包含扩展、已编译声音采集程序、Node.js 22.23.2 和桥接依赖，无需自行安装 Node、Python、npm 或 Xcode。
- **`MeetingBridge-0.6.1-extension.zip`**：仅 Chrome 扩展，适用于已经安装配套 Mac 桥接程序的用户，不能独立完成系统声音转写。
- **`SHA256SUMS.txt`**：两个 ZIP 的 SHA-256 校验值。
- GitHub 自动提供的 **Source code** 是源码快照，首次安装建议用上面的 Mac 包。

## 三步开始

1. 解压 Mac 包，双击 `Install.command`，按回车安装。更新前先停止监听。
2. Chrome 打开 `chrome://extensions`，开启开发者模式，加载 `~/Library/Application Support/MeetingBridge/extension`（选择目录时可按 ⇧⌘G 粘贴路径）。
3. 打开目标聊天网页并绑定，填写自己的百炼 API 密钥，点击「开始监听」，按系统提示授予录音权限。

更多步骤、更新、卸载和数据流见包内 `README.md`，或[安装说明](https://github.com/Syuao/meeting-bridge/blob/main/distribution/README.md)。

## 功能

- 阿里云系统声音实时转写，中英文识别，连续文本和本机历史。
- Qwen-MT 中文翻译，DeepSeek 可选；网络故障自动退避恢复。
- 原文划选后自动复制并追加草稿；保留已有草稿，手动发送。
- 可调字号、可选填入前确认，默认不弹选句浮层。

## 已知限制与费用

- 此预编译包仅支持 Apple Silicon；Intel Mac 可参考源码构建，尚未实测。
- 本机采集程序为临时签名，未获得 Apple Developer ID 签名或公证；macOS 可能要求确认开发者来源。
- 不含 API 密钥、云服务额度或离线 Whisper 模型。百炼和 DeepSeek 用量由各服务商另行计费。
- 安装和更新需要手动操作，尚无自动更新或收费激活机制。
- 录音只覆盖系统输出，不采集麦克风。关闭侧栏不会停止录音，请点击「停止」。云转写上传音频，云翻译上传待译文字；请取得所需的会议参与者同意。
- 本地 Whisper 模式需另外构建引擎、下载模型。网页改版可能影响草稿填入。
