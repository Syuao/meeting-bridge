# Meeting Bridge 0.10.0

- Added Windows x64 system-output capture through WASAPI loopback and an Edge native-messaging installer.
- Added Edge fallbacks for environments without `sidePanel` or `storage.session`.
- Windows captures the default output mix and requires Node.js 22+ plus FFmpeg with WASAPI input.
- The Windows package has not been run on a Windows machine in this macOS build environment.
